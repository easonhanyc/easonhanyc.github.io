### How the dashboard was loaded (please read before captioning)

The page loads Chart.js 4.4.1 from `cdnjs.cloudflare.com` and asciinema-player 3.7.1 from `cdn.jsdelivr.net`. Both hosts are blocked by the capture machine's network policy (the proxy answered 403), and without Chart.js the page showed "Could not load: Chart is not defined". To get a true render, the capture script answered those three requests with the same library versions downloaded from the npm registry (`chart.js@4.4.1` `dist/chart.umd.js`, `asciinema-player@3.7.1` `dist/bundle/*`). The HTML, CSS, app script and all data came live from the site and its API; nothing was mocked or drawn. A visitor's browser, which can reach the CDNs, sees the same page.

Not captured (not requested): the Trends and Review lookup tabs.
